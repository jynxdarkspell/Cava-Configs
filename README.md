# Cava-Configs
Configuration files for cava

A collection of configuration files for Cava (Console-based Audio Visualizer for ALSA).

Configuration files can be saved within ~/.config/cava/ (or anywhere else where you can remember the location).

You can save any ONE of these files as ~/.config/cava/config to replace your user default cava configuration, but
be sure to make a copy of your current configuration first, just in case!

At present, you can invoke any of these configurations (once saved) using "cava -p ~/.config/cava/configuration_file_name.config"
